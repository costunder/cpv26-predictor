# v4 입력 연결 검증 — 2026-08-31

이 기록은 입력 결함 수정과 정답 보존 검사 결과다. 새 모델의 예측 성능 평가 결과가 아니다.
v3 결과보다 승부/안타 정확도가 좋아졌다고 확인하지 않았다.

## 검사한 실데이터

동일한 로컬 canonical DB의 2001-04-05~2026-07-26, 3,968일, 15,815경기를
기존 v3 캐시와 새 v4 캐시로 비교했다. 원천 DB와 기존 캐시는 수정하지 않았다.

- v3 fingerprint: `bca9218ff935c596ede409580b009e6c3826929c372d5c2ee2f79f59c72b4b06`
- v4 fingerprint: `0d83f13bde8aecf565f81b67b2341b7ab7819a61d6df19ba4d8b67955c26efc1`
- 고정 원천/출처 75개; 원천 revision과 SHA-256은 각 manifest의 `source_provenance`에 기록된다.

v4의 NPZ 3,968개 SHA, 배열 238,080개, 과거 정보 관계 7,748,441개를 검사했다.
파일 무결성·배열 유한값·관계 정보 시점 검사를 통과했다.

## 통계 입력 단절

과거 PA 이력이 이미 있는 최근 날짜에, 선수·팀의 타격/투구 통계 4개 블록이 모두
비어 있던 v3 날짜는 588일이었다. v4에서는 같은 조건의 빈 블록 날짜가 0일이다.
각 시즌 첫날은 90일 범위에 이전 자료가 없어 0인 것이 정상이다.

| 연도 | 전체 일수 | v3 통계 입력이 있는 일수 | v4 통계 입력이 있는 일수 |
|---|---:|---:|---:|
| 2023 | 167 | 0 | 166 |
| 2024 | 163 | 0 | 162 |
| 2025 | 164 | 0 | 163 |
| 2026 부분 시즌 | 98 | 0 | 97 |

2022-07-03의 실제 타격 질의 102개도 검사했다. v3에서는 10팀 모두 팀마다
입력이 1종류였다. v4에서는 팀마다 9~12종류로, 그날의 각 질의 수만큼 구분됐다.
단, 이는 이름·팀·역할별 과거 그룹 통계의 차이다. 공식 선수 ID에 의한 개인 경력
연결을 검증한 것이 아니며, 동명이인은 여전히 같은 그룹에 포함될 수 있다.

## 기존 정답 보존

배열 순서가 아니라 query ID를 기준으로 모든 날짜를 대조했다. 아래 항목의
누락·추가·중복·값 불일치는 각각 모두 0건이다.

| 기존 정답 | 질의 수 | 대조 항목 |
|---|---:|---|
| 경기 | 15,815 | 승무패, 양 팀 득점 |
| LiveHit | 360,740 | PA, H, 최소 PA |
| 개별 PA | 206,579 | 결과, 10차원 타석 상황 |
| 2001~2022 타격 집계 | 299,194 | 10종 결과 개수 |
| 2001~2022 투구 집계 | 111,939 | 수치, 관측 마스크 |

2023년 이후의 실제 PA로 추가한 집계는 타격 59,808질의/206,579결과와
투구 25,517질의/153,102관측 필드다. 없는 득점/RBI/투구 수/아웃/실점/자책점을
합성하지 않았다. 집계 정답이 늘었으므로 v3와 v4의 전체 가중 손실 숫자는
같은 평가 항목 수를 의미하지 않는다.

## 재검사

환경과 전체 DB가 준비된 경우 [README](../README.md#4-kbo-데이터와-그래프-생성)의
v4 그래프 생성 명령을 실행한 뒤 다음 명령으로 전체 파일을 다시 검사한다.

```bash
python scripts/audit_cross_era_graph.py var/datasets/kbo_graph_2001_2026_v4 \
  --output var/reports/cross_era_v4.json
```

단위/학습 회귀에는 시점별 PA 수정·지연·만료, 출처 중복 제거, 결측 마스크,
동명이인 관측 ID 보존, 교차 시기 공통 입력의 역전파, 선택 기준과 선택적 gradient
분리를 포함한다. 테스트용 작은 사례와 위 실데이터 전수 검사를 구분한다.

새 v4 모델의 정확도는 새 run을 학습하고 별도 평가해야 알 수 있다. 기존 2026 결과를
반복해서 보고 선택한 변경은 독립적인 미관측 테스트 성능이라고 주장하지 않는다.
